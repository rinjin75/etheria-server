# ETHERIA — подключение админ-панели

Сайт остаётся на GitHub Pages. Админ-панель уже имеет интерфейс, но публикация отключена, пока владелец не подключит Firebase. Не вводите пароль в код и не добавляйте секретные ключи администратора в репозиторий.

1. Создайте проект в Firebase Console. Добавьте Web App и скопируйте публичную конфигурацию в `firebase-config.js` вместо null.
2. В Firebase Authentication включите Email/Password. Создайте **одного пользователя-владельца** и скопируйте его UID в `window.ETHERIA_OWNER_UID`. Настройте разрешённые домены входа (включая rinjin75.github.io).
3. Создайте Firestore Database и Cloud Storage (Storage может потребовать платёжный тариф).
4. В файлах `firestore.rules` и `storage.rules` замените `REPLACE_WITH_OWNER_UID` на UID владельца и опубликуйте эти правила в консолях Firestore и Storage. Никогда не публикуйте тестовые правила с открытой записью.
5. Загрузите обновлённый `firebase-config.js` в тот же репозиторий. Войдите на `admin.html` с учётными данными Firebase.
6. Создавайте публикации с заголовком, текстом, фотографией, датой и сроком окончания. Просроченные публикации скрываются на сайте автоматически, но остаются в базе, пока их не удалить.

Важно: скрыть саму ссылку на панель от всех посетителей нельзя на статическом сайте; безопасность обеспечивают вход и правила доступа Firebase. Публикации доступны публично для чтения. Если вы не подключаете Firebase, сайт показывает локальный `content.json` и админ-панель не позволяет публиковать.
